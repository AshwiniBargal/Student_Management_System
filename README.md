# Student Management System

A web-based Student Management System developed using Java, JSP, Servlets, PostgreSQL, and Apache Tomcat. The application helps manage student records, including adding, updating, deleting, and viewing student information through a user-friendly interface.

## Features

- Add new student records
- View all students
- Update student details
- Delete student records
- Search students
- Responsive and simple user interface
- PostgreSQL database integration

## Tech Stack

- Java
- JSP (JavaServer Pages)
- Servlets
- JDBC
- PostgreSQL
- Apache Tomcat
- HTML
- CSS
- Eclipse IDE

## Prerequisites

- Java JDK 17 or above
- Eclipse IDE
- Apache Tomcat
- PostgreSQL
- pgAdmin

## Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/StudentManagementSystem.git
```

2. Import the project into Eclipse.

3. Create the PostgreSQL database and required tables.

4. Update the database credentials in `DBConnection.java`.

5. Configure Apache Tomcat.

6. Run the project on the server.
